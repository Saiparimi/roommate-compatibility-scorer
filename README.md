# 🛏️ Roommate Compatibility Scorer

A rule-based scoring system to measure how compatible two roommates are based on daily lifestyle preferences.

## Features

- Inputs: Sleep time, cleanliness, work schedule, food habits
- Outputs: Compatibility score (0–100)
- Ranks the most compatible roommate from a list

## How to Run

1. Clone the repository
2. Run the script:

```bash
python main.py
```

## Sample Output

```
Top Compatible Roommates:
Alice: 100/100
Diana: 75/100
Fay: 70/100
```
